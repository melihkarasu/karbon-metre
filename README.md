# 🌱 Web Karbon Ayak İzi & Eko-Skor

The Green Web Foundation & Sustainable Web Design (SWD v4) standartları ile web sitelerinin sayfa yükleme başına CO2 salımı, yeşil hosting analizi, yıllık çevresel etki simülasyonu ve gömülebilir eko-rozet üreticisi.

## ✨ Özellikler
- **Sayfa Başına Karbon Emisyonu Hesabı:** Sustainable Web Design (SWD) modeli ile sayfa boyutu, veri transferi ve sunucu enerji tüketiminden gram CO2e hesabı.
- **Eko-Skor Harf Notu (A+ &ndash; F):** Küresel web sayfası emisyon dağılımına göre bağımsız çevre dostu not karnesi.
- **The Green Web Foundation Canlı Entegrasyonu:** Alan adının yenilenebilir enerji kullanan yeşil veri merkezlerinde barınıp barınmadığının anlık kontrolü.
- **Yıllık Çevresel Etki Simülasyonu:** 1.000 &ndash; 100.000 aylık ziyaretçi aralığında interaktif slider:
  - Yıllık CO2 salımı (kg)
  - Salınan karbonu dengelemek için gereken ağaç sayısı
  - Elektrikli araç sürüşü eşdeğeri (km)
  - Akıllı telefon şarjı adedi
- **Gömülebilir SVG Eko-Rozet:** Web sitenizin footer veya README alanına dinamik olarak yerleştirebileceğiniz HTML ve Markdown rozet kodları.
- **Son Taramalar Geçmişi:** İncelediğiniz web sitelerinin eko-notlarını LocalStorage üzerinde güvenle saklar.
- **%100 Sunucusuz & Ücretsiz:** Herhangi bir API anahtarı veya backend gerektirmez; açık The Green Web Foundation servisi ve istemci hesaplama motoruyla doğrudan tarayıcı üzerinden çalışır.

## 🚀 Hızlı Başlangıç
1. Bu repoyu klonlayın:
   ```bash
   git clone https://github.com/melihkarasu/karbon-metre.git
   cd karbon-metre
   ```
2. `index.html` dosyasını doğrudan herhangi bir web tarayıcısında açın veya [GitHub Pages](https://melihkarasu.github.io/karbon-metre/) üzerinden canlı kullanın.

## 🔑 API & Metodoloji
Bu uygulama herhangi bir özel API anahtarı veya yetkilendirme **gerektirmez**:
- **Yeşil Hosting Kontrolü:** [The Green Web Foundation Greencheck API](https://www.thegreenwebfoundation.org/tools/greencheck-api/) (Açık, ücretsiz ve CORS destekli).
- **Emisyon Standardı:** [Sustainable Web Design (SWD) Model v4](https://sustainablewebdesign.org/calculating-digital-emissions/).
